# Security Policy

## Report privately
Do not open a public issue, discussion, or PR for a suspected vulnerability. Use [GitHub private vulnerability reporting](https://github.com/PedriniFerdi/ApplyFlow/security/advisories/new).

Include the affected component and version, reproduction steps, security impact, known mitigations, and safe contact details. Remove credentials, tokens, personal data, and unrelated sensitive information.

## Response
Maintainers will acknowledge the report privately, assess its scope and severity, and coordinate remediation and disclosure. Allow a reasonable investigation period before public disclosure.
